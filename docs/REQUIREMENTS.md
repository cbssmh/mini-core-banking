# Purpose

Mini Core Banking v2 defines the next stage of the system as a reliable transfer service.

The primary goal is to make money movement between accounts consistent, auditable, and safe under concurrent access.

# Functional Requirements

- Create Account
- Get Account
- Deposit
- Withdraw
- Transfer
- Transfer History

# Non Functional Requirements

- Atomic Transfer
- Transaction Consistency
- Idempotency
- Concurrency Safety
- Auditability
- Testability
- Maintainability
- Observability

# Non Goals

The following capabilities are not part of v2:

- OAuth
- Multi Currency
- Loan
- Card
- Microservice Architecture
- Kafka Cluster
- Kubernetes
- External Payment Network Integration
- Event Sourcing
- CQRS
